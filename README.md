# Vanilla UI Overhaul

Replaces the default white and yellow UI elements with a dark, semi-transparent style. Panels turn into frosted glass, yellow hover effects become blue, and the main menu re-centers itself. The loading screen and spawnmenu are restyled to match.

> **Beta** — things might change. Bug reports welcome via [Issues](https://github.com/qudeowl/vanilla-ui-overhaul/issues).

---

## Features

- Centered main menu with smooth hover animations
- Blue accent system replacing the default yellow highlights
- Dark glass panels across menus, server browser, and spawnmenu
- Restyled loading screen, workshop cards, dropdowns, and scrollbars

---

## Installation

**Automatic**
1. Download `install_vanilla_ui_overhaul.bat` from the [latest release](https://github.com/qudeowl/vanilla-ui-overhaul/releases/latest) and run it
2. The script will find your GMod folder automatically and install the files
3. Launch Garry's Mod

> Make sure the game is closed before running the installer.

**Manual**
1. Download `Vanilla_UI_Overhaul_Beta.zip` from the [latest release](https://github.com/qudeowl/vanilla-ui-overhaul/releases/latest)
2. Extract and drop the `garrysmod` folder into `...\Steam\steamapps\common\GarrysMod`

---

## Uninstall

Verify your game files on Steam to revert everything back to default.

`Steam Library → Garry's Mod → Properties → Installed Files → Verify integrity of game files`
